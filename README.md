# 시라 글쓰기 · SIRA WRITING

시라의 철학을 글쓰기라는 매개체로 경험하는 글쓰기 커뮤니티입니다. 시라는 내면의 건강, 외면의 건강, 정신적인 건강이 균형을 이루는 삶을 지향합니다.

## 첫 MVP 원칙

- 로그인한 회원만 서비스를 이용할 수 있습니다.
- 관리자가 기수와 수동 Club을 개설합니다.
- 수동 Club에는 클럽장이 없습니다.
- 수동 Club은 기본적으로 모든 로그인 회원이 자유롭게 글을 쓸 수 있습니다.
- Club 주제는 관심 분야, 한 문장의 주제, 2~3문장의 설명으로 구성합니다.
- 종료된 기수와 글은 삭제되지 않고 보관됩니다.
- 향후 회원 제안형 Club, 참가 모집, Club 성립 여부를 활성화할 수 있습니다.

## 확장 원칙

Club의 개설 방식(`origin_type`), 참여 방식(`participation_mode`), 읽기·쓰기 범위를 각각 분리합니다. 참여형 Club이 필요해지면 `club_memberships.role_code`에 `LEADER` 등의 역할을 추가하며, 역할의 실제 권한은 별도 정책으로 확장합니다.
